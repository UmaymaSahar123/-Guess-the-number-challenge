# Guess the number 
A simple Python game where the player tries to guess a randomly generated number.

## About the game 
The computer chooses a number, and the player keeps guessing until they find the correct number.

## Language used 
Python.

## Project
This is a beginner python project created to practice programming fundamentals.

## What I learned
This project helped me practice concepts such as variables, user input, conditions, loops, and random 
number generation.
